# Wollumetric for Processing

A Processing library for rendering 3D scenes on a Wollumetric display.

Adapted from Albert Hwang's [lumarca-for-processing](https://github.com/Albert/lumarca-for-processing), extended with mesh/OBJ rendering via voxelisation and per-string calibration.

**Requires Processing 4.x** (Java 17+, OpenGL 3.2+).

---

## Usage

A standard 3D Processing sketch:

```java
void setup() {
  size(1920, 1200, P3D);
}

void draw() {
  sphere(60);
}
```

Becomes a Wollumetric sketch with minimal changes:

```java
import wollumetric.*;

Wollumetric w;

void setup() {
  size(1920, 1200, Wollumetric.RENDERER);
  w = new Wollumetric("wollumetricConfig.json", this);
}

void draw() {
  sphere(60);
}
```

## Config File

Place a `wollumetricConfig.json` in your sketch's `data/` folder alongside the wiremap file:

```json
{
  "version": "2.0.0",
  "wiremapFile": "radius-480-48x30-2.2-170.0_strings.txt"
}
```

| Key | Description |
|-----|-------------|
| **wiremapFile** | Path to a `_strings.txt` wiremap file (in `data/`). Generated by py-scripts. |
| **structureWidth** | Physical width at the near plane, in real units\*. *(parsed from filename if omitted)* |
| **structureDepth** | Physical depth of the display, in real units\*. *(parsed from filename if omitted)* |
| **throwRatio** | Projector throw ratio (distance / image width). *(parsed from filename if omitted)* |
| **margin** | Black pixels between each string column. Default `0`. |
| **mapCache** | Internal - delete this key or the cached `.png` to force map regeneration. |

\*Units can be centimeters, inches, etc. - stay consistent.

---

## Supported Processing Features

All non-graphics features work normally (mouse, keyboard, data, sound, etc.).

**Supported graphics:**

- `sphere()`, `box()`
- `shape()` - loads OBJ meshes, rendered via voxelisation
- All matrix transforms (`translate`, `scale`, `rotate`, etc.)
- `fill()` with alpha
- `background()`

**Not supported** (not relevant to volumetric rendering):

- Textures, lighting, camera

## Examples

| Sketch | Description |
|--------|-------------|
| **WollumetricBasicGeo** | Sphere + rotating box - basic primitives |
| **WollumetricColors** | Per-string colour mapping (HSB by position) |
| **WollumetricMesh** | OBJ model rendering with `shape()` + `setVoxelResolution()` |
| **WollumetricCalib** | Interactive per-string calibration tool |
| **WollumetricTest** | Raw projector line editor for hardware alignment (no library) |
